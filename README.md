# Task CRM

**Versão própria do DeskcommCRM (WhatsApp + IA + multi-tenant).**

Atualizações do produto TASK — apenas uso interno da Cozmos — não se aplica a outras instalações.

## Rodando

```bash
git clone https://github.com/CozmosAI/Task-crm-v2.git
cd Task-crm-v2
pnpm install
pnpm dev
```
